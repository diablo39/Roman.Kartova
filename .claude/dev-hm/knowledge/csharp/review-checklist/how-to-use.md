# C# review checklist — How to use

Section of `knowledge/csharp/review-checklist.md`.


1. Scope the diff; identify project type (library, ASP.NET service, console, generator) and whether
   the target is AOT/trim.
2. Walk each category below against the changed code.
3. Run the oracle addendum entries; record fail/waiver per ID, passes as counts.
4. Report findings grouped by severity, each with a `file:line`, the rule, and the fix.
