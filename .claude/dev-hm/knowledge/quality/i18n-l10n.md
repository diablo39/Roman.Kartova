# Internationalization and localization

Locale correctness for products shipped into multi-language markets — for Volue, the EU baseline:
several languages, several number and date conventions, one codebase. i18n defects are reviewed
as `finding` lines tagged with the ISO/IEC 25010 characteristic they degrade — functional
suitability when a value is computed, parsed, or displayed wrongly for a locale; interaction
capability when a user cannot operate the product in their language or script — with severities
from `knowledge/shared/severity-tiers.md`. No deterministic core oracle
entry covers this territory; the accessibility entries (QUA-110/111) are adjacent but distinct.
Standards and library editions cited here are anchored in
`knowledge/shared/versions.md`.
