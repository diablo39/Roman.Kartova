# Review method

The severity-tiered procedure for reviewing a code change, the finding format, and the topic
walkthroughs the quality oracle points at. This is the method shared by developer self-checks,
language code reviewers, and the two gate agents; the layer responsibilities and verdict grammar
are fixed in `knowledge/shared/defense-in-depth.md`, severities in
`knowledge/shared/severity-tiers.md`.
