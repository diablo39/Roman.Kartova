# Quality characteristics in review (ISO/IEC 25010:2023) — Functional suitability

Section of `knowledge/quality/quality-characteristics.md`.


Sub-characteristics: functional completeness, correctness, appropriateness. In review:
completeness is checked against the work package's acceptance criteria, not against the code
itself (a fully implemented wrong scope still fails — ISTQB P7); correctness is what the test
suite asserts (QUA-002/003); appropriateness asks whether the diff solves the task without
gratuitous extras — unrequested features enlarge the attack and maintenance surface and are
findings, not bonuses.
